# My Digital Space (GameBox)

A personal digital space and game tracking portfolio built with Vue 3, Vite, Pinia, and Vue Router.

## Features

- **Dynamic Theme**: Light, airy design with animated gradient backgrounds and glassmorphism effects.
- **Terminal Intro**: A retro-tech terminal interface on the landing page introducing the user.
- **Waterfall Layout**: Masonry-style layout for showcasing content.
- **Game Library**: Track your game collection with statuses (Playing, Completed, Backlog).
- **Learning & Notes**: Sections for documenting technical growth and daily thoughts.
- **Statistics**: Visual breakdown of your gaming habits.

## Project Setup

```sh
npm install
```

### Compile and Hot-Reload for Development

```sh
npm run dev
```

### Compile and Minify for Production

```sh
npm run build
```
